# Personal Portfolio

A handcrafted portfolio built from scratch to showcase my projects, interests, and approach to software engineering. Instead of using templates or website builders, I focused on creating a fast, responsive, and interactive experience using vanilla web technologies.

## Design Highlights

- Multi-panel hero with smooth scroll interactions
- Responsive layout for desktop, tablet, and mobile
- Interactive technology explorer with project highlighting
- Project case studies presented in modal overlays
- Custom animations, transitions, and hover effects
- Resume preview and download modal

## Built With

- HTML5
- CSS3
- JavaScript (ES6)
- CSS Grid & Flexbox
- Intersection Observer API
- GitHub Pages

## Local Development

```bash
git clone https://github.com/sameerapujari/MyPortfolio.git
cd portfolio
```

Open `index.html` in your browser, or use a local server such as VS Code Live Server.
